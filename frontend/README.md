# Gestor Financiero

Frontend React + Vite para consultar, registrar y eliminar movimientos financieros.

## Desarrollo

```bash
npm install
npm run dev
```

La API se configura con `VITE_API_URL`. Si no se define, se usa `http://localhost:8000`.

```bash
VITE_API_URL=http://localhost:8000 npm run dev
```

## Validacion

```bash
npm run lint
npm test
npm run build
```
